# 个人工作台架构与执行合同

浏览器 → Paperclip Web/API → PostgreSQL/附件 → Pi 本地或 SSH execution target。
Tailscale 只负责网络；应用会话／Agent bearer 身份仍由 Paperclip 验证。

## 数据来源

- 需求、个人事项、分析任务、代办子任务全部是 Issues；父子、评论、文档、执行状态、运行和费用全部复用上游。
- `personal_todos` 仅存个人设置：用户归属、日期、时区、重复、类别、分析范围、Pi 协调 Agent、当前建议、关联分析／草稿、后继实例与创建幂等键。
- 标题、描述和状态只有 Issues 一份。当前内容／授权 SHA-256 是评估版本；修改内容、授权或完成待办后旧建议不能创建草稿。
- 评估历史留在分析任务及 HeartbeatRun；草稿成为原待办的 issue document，并记录来源 Agent/Run。侧表随 Issue 删除级联；其他保留策略沿用上游。历史实例不会被重复规则覆盖。

## 调度

只有 Paperclip scheduler 的现有 tick 调用个人待办筛选／结果归集，不新增 timer 或 daemon。持久个人分析／草稿 Issue 是启动意图；tick 重查未开始的个人子任务并调用原有 assignment wake 路径，启动失败不会只留在浏览器内存。

程序在发给 Pi 前检查协助开关、版本、待办非终态、Agent 类型／公司／状态。滚动 24 小时最多五次分析，每个版本只创建一次分析。开启每日检查仅复查变更版本，空闲不调用模型。拒绝当前版本后不重复产生同版代办。

评估使用严格 JSON schema。模型没有授权字段；建议为 external_action / human_action / needs_information 时不能自动执行。只允许无工具草稿／清单。采纳和自动协助使用同一事务、Issue 行锁、版本／去重判定，重复点击只返回已有子任务。

当前分析无工具调用，因此由程序验证完成的运行输出并记录评估；草稿程序归集到文档。程序不把原个人事项勾选完成。人类完成／撤销完成分别改变原任务状态。每天／每周重复事项当前实例完成时在同一事务产生一次后继；撤销再完成不产生第二个后继。

## 控制和故障

- Pause Agent：上游暂停语义／预算门禁；不把它当已停止远端子进程的证据。
- Stop Run：使用上游真实运行控制界面；只有实际停止证据才视为停止，不写假成功状态。
- 修改待办／撤销协助：旧分析／草稿取消未来工作。已进行推理可能仍结束，但结果会被版本与当前授权拒绝；本功能没有外部副作用工具。
- 自动扫描遇到 Agent 暂停／预算／授权问题，保持真实任务和日志；最多每天重新检查。失效输出不能被当有效建议。
- 浏览器关闭：中心继续；中心关闭：不调度，持久记录保留。重启依赖上游的队列、controller lease 和恢复核对；不承诺任意 shell exactly-once 或跨设备透明迁移。
- 普通 Agent 的权限由上游 API、执行层及 OS 共同决定。本功能禁止 Agent 直接修改人类个人任务字段；助手只操作独立授权子任务。公司级可读任务仍是上游的可见性边界。
